# ScrcpyGate 界面布局规范

本规范适用于 `static/pages/` 的全部十个页面。以 [Apple HIG Layout](https://developer.apple.com/design/human-interface-guidelines/layout)、[Labels](https://developer.apple.com/design/human-interface-guidelines/labels) 和 [Segmented controls](https://developer.apple.com/design/human-interface-guidelines/segmented-controls) 的信息层级与交互原则为参考，沿用项目现有配色、字体、图标、原生 HTML/CSS/JS 以及深浅色主题。它不是 iOS 外观的逐像素复刻。

## 层级与位置

1. 页面顶栏用于全局导航、账户和主题；页面标题只说明当前页面，页面级刷新或主要创建动作可与标题并列。
2. 会替换整块页面内容的选择器紧接标题放置，使用同一套分段控件尺寸与选中态。仅影响一张表、一个图表或一个弹窗的选择器留在对应内容区内，靠近被控制的内容。
3. 页面主体按任务分组。每组只保留一个外层容器；标题、筛选、结果与分页属于同一任务时，不再各画一张卡片。容器内优先用间距、文字权重和背景区分层级，只在扫描长列表确有帮助时使用分割线。
4. 常用操作放在它影响的标题、工具行或内容附近；保存和重置位于表单末尾。危险操作保留清楚的文字、颜色与确认流程。
5. 说明文字简短并紧贴字段或信息按钮。错误、风险、执行结果和运行状态直接可见，不能只放在悬停提示中。设备地址、IP、时间和日志等有用文本应可选择与复制。

## 页面归属

| 页面 | 首要任务 | 页面级选择 | 局部选择或次要区域 |
| --- | --- | --- | --- |
| 登录 | 完成身份验证 | 无 | 语言、主题和验证码状态随表单显示 |
| 投屏工作台 | 保留画面最大可用空间 | 单画面 / 宫格视图随设备区显示 | 左侧导航只显示名称；画质、控制、记录和账户内容在各自面板中切换 |
| 仪表盘 | 扫描设备与待处理状态 | 无 | 设备状态筛选与告警切换留在所属面板 |
| 设备管理 | 浏览设备与查看详情 | 无 | 搜索和筛选归设备列表，详情跟随当前设备 |
| 用户与权限 | 浏览、筛选和管理用户 | 无 | 用户列表内筛选；到期策略是独立可收起区域 |
| 画质与传输 | 配置画质、传输与会话 | 画质档位 / 传输链路 / 会话策略 | 预设操作留在预设区 |
| 投屏管理 | 按角色配置工作台 | 管理员 / 普通用户 | 按钮层级切换留在对应设置项 |
| ALAS 管理 | 查看归属、配置与状态 | 用户与归属 / 配置目录 / 隐藏范围 | 状态摘要跨视图可见；列表筛选留在列表 |
| 安全机制 | 管理访问、封禁、地域与登录 | 四个安全分区 | 各分区内的筛选和下载设置留在该分区 |
| 日志审计 | 检索运行与审计记录 | 无 | 运行日志 / 安全审计属于日志面板；结构化 / 原始视图属于运行日志 |

## 度量与响应

- 后台使用紧凑的 36px 常规控件和 16px 内容间距；触屏或窄屏的主要控件至少 44px 高，页面间距缩为 12px。具体值由 `admin-workspace.css`、`interface-controls.css` 和现有令牌维护。
- 后台侧栏只呈现一级导航名称；仪表盘和日志概览使用紧凑信息带。设备与 ALAS 的状态摘要使用更小的独立卡片，窄屏两列换行，长状态文字自然换行。
- 同级卡片使用同一圆角令牌；输入框、按钮和弹窗按各自语义使用较小或较大的圆角。胶囊只用于状态、选择和少量强调，不把每段文字都包成胶囊。
- 标题、标签、辅助信息、数值和操作按阅读顺序排列。字段须有可见标签或明确的无障碍名称；占位文字不能代替字段名。中英文文案都应允许自然换行。
- 手机与平板按可用宽度重排，不让固定宽度造成页面横向溢出。分段控件空间不足时可横向滑动且隐藏滚动条，但键盘仍能逐项聚焦。投屏画面优先于侧栏和工具栏；全屏时只保留必要控制。
- 深浅色下都用现有语义色表示成功、警告、错误和选中。颜色之外还保留文字、图标或状态名称。键盘焦点始终可见；动画遵循系统减少动态效果偏好。

## 修改检查

改动一个页面时，检查它在标题、一级选择、任务容器、局部操作、保存区、弹窗中的位置是否符合上表；再检查桌面、平板、手机、长文本、深浅色、键盘和触屏。布局改动不能更改现有 API、权限、WebSocket 或业务状态语义。
