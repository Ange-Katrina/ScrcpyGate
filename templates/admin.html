ALAS 使用帮助
  1. 必须先安装并启动 Alas-Gyre 的 Overlay Runtime。只有 Overlay 正常运行后，ScrcpyGate 才能使用 ALAS 的启动、停止、重启功能。
  2. ScrcpyGate 只是代理控制入口，不会直接运行 ALAS，也不会替代 Overlay。普通用户前台只调用自己绑定配置的启动/停止/重启。
  3. 在“连接设置”里填写 Overlay 的 Runtime URL 和访问 Token，然后在“用户授权”中为每个用户分配一个或多个配置。
  4. 如果状态显示 token 未配置、连接失败或 ALAS control is disabled，先检查 Overlay 是否已启动、URL 是否能从服务器访问、Token 是否一致。
  5. 用户只能看到已授权给自己的配置；配置内容、其他用户关系与 Runtime Token 不会暴露到普通用户前台。
ALAS 官方仓库Alas-Gyre Overlay 仓库

默认 Runtime 地址通常类似 http://127.0.0.1:22267。如果 ScrcpyGate 在 Docker 或另一台服务器上，需填写容器/服务器可访问的 Overlay 地址。
